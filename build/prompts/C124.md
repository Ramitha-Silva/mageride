## Scope
The full delivery pipeline: build -> test -> contract -> image -> promote -> deploy, with K3s/DOKS
manifests, gated migrations and a rollback path.

**Fences — do not cross these:**
- DB migrations are gated pre-deploy and must be backward-compatible with the running version.
- Rollout is RollingUpdate with maxUnavailable 0, maxSurge 1. No big-bang deploys.
- Secrets come from Vault via External Secrets Operator — never from repository files.

## Deliverables
- complete .github/workflows with dev -> staging -> prod promotion by image SHA
- K3s + DOKS manifests — Deployments, Services, HPAs, StatefulSets (EMQX/Redpanda/Postgres/tcp-adapter), Ingress with WSS, ConfigMaps/Secrets
- ArgoCD app-of-apps definitions and sync policies
- migration gate job, image signing/tagging, rollback runbook
- secrets management — sealed-secrets/Vault + External Secrets Operator wiring and a rotation procedure

## Definition of Done
- a commit to main produces signed images and a staging deploy without manual steps
- a failed migration blocks the deploy and leaves the previous version serving
- a rollback to the previous SHA completes and is documented step by step
- no secret value exists in the repository
