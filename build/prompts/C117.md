## Scope
The six no-login pages at `passenger.mageride.lk`, served from public-bff and styled with the
same Tailwind preset. ADD: [AL-44, AL-45, AL-48, AL-52, D-33, D-34, P-02, P-09, P-10, P-14,
US-25.1..US-25.6, US-26.3].

**Fences — do not cross these:**
- No app chrome, no login. The token IS the credential; render nothing before it validates.
- The driver card carries a plain `tel:` link. There is no /call round-trip, no masked number, no confirm-your-number step (AL-48).
- Decline on SCR-WT-003 transmits NO GPS, and the copy must say so.
- Mobile-first at 375 px; this is a subview of the Passenger App, not a separate product.

## Deliverables
- portals/web-passenger Next.js app consuming @mageride/tailwind-preset and public-bff
- SCR-WT-001 token gate — validate, route by scope, <=1 s spinner, no data before validation
- SCR-WT-002 package track — SSE live position, 4-step status, 4-digit delivery OTP, driver/vehicle card, Call driver (tel:)
- SCR-WT-003 confirm pickup — 5-min TTL countdown, adjustable pin, Share location / Decline with the "declining never sends your GPS" note
- SCR-WT-004 ride track — driver name/photo, vehicle + reg, ETA, progress polyline, Start OTP, cash-due notice, Call driver (tel:), SOS with browser GPS
- SCR-WT-005 delivered/receipt — OTP-verified / photo-proof / COD collected / Disputed outcomes + Download receipt
- SCR-WT-006 expired/invalid — safe dead end, zero ride data, app-download link

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- an expired or unknown token renders SCR-WT-006 with no ride data in the DOM or network payload
- the live feed reconnects after a dropped SSE stream without a full reload
- a web pickup-confirm resolves the same location request the app would
- Lighthouse mobile passes with no horizontal scroll at 375 px
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
