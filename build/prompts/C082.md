## Scope
Mode B private-transport access and the subscriber-side payment experience.
ADD: [AL-23, AL-24, AL-25, AL-49, D-22, US-4.x, US-23.x].

**Fences — do not cross these:**
- Requests are PER VEHICLE with the Vehicle ID pre-filled when opened from a marker (AL-23).
- Unsubscribing loses visibility immediately; re-joining requires request -> accept (AL-25).
- The pay sheet renders the owner's VERIFIED bank details / LankaQR image — never unverified data (AL-49).

## Deliverables
- access request — Vehicle ID (pre-filled or typed), request + pending/accepted/rejected states
- my subscriptions — per-vehicle cards with Paid (amount/mo + next due) or Free, 💳 Pay, 🧾 history, compact ✕ unsubscribe, muted-until-owner-deletes note
- subscription payment — LankaQR deep link / LankaQR scan / OnePay (+5 %) / online transfer with screenshot attach
- payment history — month, date, method, amount, status (Paid / Pending verification / Paid-cash)

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- unsubscribing removes the vehicle from the live map within seconds
- an online-transfer payment shows Pending verification until the owner confirms
- the pay sheet shows the correct payTo for the owning org
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
