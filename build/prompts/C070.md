## Scope
The driver home state machine: the Mode C standby dashboard, the Mode A/B Start/End Journey
dashboard, Directional Travel, the 15 s dispatch offer and the active ride.
ADD: [R-01, R-02, DT-01..DT-08, AL-31, AL-32, AL-47, AL-48, US-9.6].

**Fences — do not cross these:**
- ride-svc != trip-state-svc: SCR-DA-010/014/015 talk to ride-svc + dispatch-svc; SCR-DA-011 talks to trip-state-svc. Never cross it (R-01).
- The home map shows ONLY the driver's own active vehicle (AL-31).
- SCR-DA-012 is [MERGED -> SCR-DA-010] — the standby toggle is a dashboard state, not a screen (AL-46). Do not build it.
- Go-online is disabled until a vehicle is available; the empty state routes to SCR-DA-026a.

## Deliverables
- Mode C dashboard — go-online toggle with gating, own-vehicle map, live reg no, wallet/fee warnings, no hamburger
- Mode A/B dashboard — Start Journey / End Journey only, vehicle type + number below the route card, ignition auto-start banner with manual override (AL-32)
- Directional Travel — destination search/map/Home, remaining uses + duration, Set Direction / Turn Off, persistent active banner
- incoming dispatch — 15 s countdown, accept/reject, proxy "Third-party booking" badge, package badge + size, Directional badge, audio + haptic
- active ride — arrive/start/complete, navigation, SOS, call (Free VoIP vs direct dial), QR-payment-received confirm sheet (AL-47)
- nav drawer menu with the eight documented destinations

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- selecting a Mode A/B vehicle routes Home to SCR-DA-011 instead of SCR-DA-010
- the offer countdown expires exactly at 15 s and the screen returns to standby
- the home map never renders another driver's vehicle
- the QR confirm sheet posts driver-qr/confirm and reflects DriverConfirmedQR
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
