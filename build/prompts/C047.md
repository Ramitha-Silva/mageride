## Scope
The Namma-Yatri-style zero-commission fee model: 7-tier daily platform fee for Mode C, the
Mode B monthly platform fee, and the admin rate/voucher-tier configuration.
ADD: [D-13, AL-01, AL-03, AL-09].

**Fences — do not cross these:**
- There is no per-trip fee and no commission. Ever.
- The first trip of each Asia/Colombo day is always free; the fee is deducted before the 2nd trip.
- Mode A (bus/train) pays nothing.

## Deliverables
- GET /v1/fees/rates, /fees/{driverId}/today, /fees/{driverId}/history
- POST /internal/fees/{driverId}/charge-before-trip — idempotent on (driver_id, vehicle_id, fee_date) in Asia/Colombo (D-13)
- Mode B monthly platform charge per vehicle (~Rs 300, first month free) incl. consolidated fleet invoicing hand-off (AL-03)
- PUT /v1/admin/fees/rates and PUT /v1/admin/voucher-discount-tiers (Admin Portal config)
- fee-refund request intake routed to support/finance (US-14.11)

## Definition of Done
- charging twice on the same (driver, vehicle, Asia/Colombo date) debits once
- the first trip of a day never charges; the second charges the vehicle-type rate
- a Mode A vehicle is never charged a daily fee
- a rate change through admin applies from the next charge without retro-billing
