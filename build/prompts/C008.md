## Scope
The single public HTTP entry point: YARP reverse proxy, the app-version gate, attestation
enforcement, and edge rate limiting. Includes the version-check service surface.
ADD: [D-30, D-31, AL-53].

**Fences — do not cross these:**
- MQTT (8883) is TCP passthrough at HAProxy and never routed through this gateway.
- SignalR /hubs is proxied with WebSocket upgrade and long read timeouts, not buffered.
- No business logic in the gateway.

## Deliverables
- backend/src/ApiGateway — YARP route/cluster config for every /v1 service + /hubs passthrough
- X-App-Version + X-Platform middleware -> 426 Upgrade Required {updateUrl, latestVersion, isMandatory} (D-31)
- X-Attestation middleware — Play Integrity (Android) / App Attest (iOS) on auth, payment, ride-accept, wallet and SOS routes -> 401 attestation-failed (D-30)
- GET /v1/version/check endpoint + version floor configuration
- per-route rate limits, request-id / traceparent propagation, problem+json error passthrough
- backend/src/ApiGateway.Tests

## Definition of Done
- a request below the version floor gets 426 with the documented body
- a sensitive route without a valid attestation header gets 401 attestation-failed; a non-sensitive route is unaffected
- the route table resolves every service named in backend/contracts/
- a SignalR handshake completes through the gateway in an integration test
