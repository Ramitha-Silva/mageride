**Fences — do not cross these:**
- The four named document slots are: Registration copy (CR book) · Insurance certificate · Revenue license · Route permit (Mode A required). No generic dropzone (AL-50).
- The label is "Service payment" (Free / Paid), not "Mode B classification" (AL-51). The API path and DB column are unchanged.

## Deliverables
- vehicle onboarding — single add + bulk CSV with per-row validation and a downloadable error report; per-vehicle named document slots each with AI extraction and a Verified / Pending / Missing chip; status table with Documents and Service payment columns
- Service payment control — Free / Paid + default monthly fare for Paid, gated on a Verified payout profile
- driver assignment — assign/revoke by User ID or phone across one or more vehicles, assignment history, temporary assignments
- tracker binding — IMEI/MAC entry, bulk binding, publish-cadence profile, credential status

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- a Mode A vehicle cannot reach Approved while the route permit is Missing or Pending
- a bulk CSV with bad rows imports the good ones and offers the error report
- selecting Paid is blocked with a clear message while the payout profile is unverified
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
