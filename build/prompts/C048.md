## Scope
Epic 23 — per-vehicle Mode B access requests, grants, subscriptions and subscriber payments,
routed to the fleet owner as a pass-through. ADD: [AL-23, AL-24, AL-25, AL-49, AL-51, D-22].

**Fences — do not cross these:**
- Access requests and grants are PER VEHICLE, never account-global (AL-23).
- Subscription money is a pass-through to the fleet owner. MageRide holds none of it and takes no cut.
- `payTo` comes only from a VERIFIED fleet payout profile; Paid classification 409s until then (AL-49).
- Unsubscribed rows stay MUTED until the owner hard-deletes them (AL-25).

## Deliverables
- POST/GET /v1/mode-b/{vehicleId}/access-requests + accept/reject creating a grant and starting a subscription
- GET /v1/mode-b/subscriptions/{passengerId}, POST /{id}/unsubscribe -> grant.status='unsubscribed' + revocation push (D-22)
- subscription.subscriptions — Paid/Free, overridable per-subscriber monthly fare, cycle ∈ month_first | join_anniversary, next_due
- POST /v1/mode-b/subscriptions/{id}/pay returning payTo (signed LankaQR image URL or bank/branch/account details) from the verified payout profile
- transfer-slip upload -> pending_verification, owner confirm, owner mark-cash-received; OnePay webhook + LankaQR confirm
- GET payment history for both passenger (SCR-PA-025b) and owner (SCR-FP-012)

## Definition of Done
- a passenger who unsubscribes immediately loses Mode B visibility via the fanout revocation path
- re-joining requires a fresh request -> accept; the muted row is still visible to the owner until deleted
- a join on 5 June with join_anniversary cycle sets next_due to 6 July
- pay returns payTo only from a verified profile; an unverified org yields 409 payout-profile-not-verified
