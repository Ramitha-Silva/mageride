## Scope
The on-device SQLite database, single-sourced across Android and iOS via SQLDelight, exactly as
specified in mobile_db_schema.md. ADD: [R-14, R-17, R-18, D-26, D-34, MAP-09].

**Fences — do not cross these:**
- One database file per app — passenger and driver schemas do not merge.
- Never store a raw token or OTP in plain SQLite; secure storage is C014's SecureStore.

## Deliverables
- shared/kmp/src/commonMain/sqldelight — all §1 shared tables, §2 passenger tables, §3 driver tables
- command_outbox — durable idempotent command queue with retry/backoff (R-14, R-18)
- gps_buffer — local ring buffer feeding MQTT pos/replay with monotonic seq (R-17, US-15.1)
- sync + eviction strategy per §4 (write path, read path reconcile, retention)
- expect/actual driver factory + SQLCipher key handling

## Definition of Done
- every table in mobile_db_schema.md §1-§3 exists with its documented columns and indexes
- a queued command survives process restart and is replayed exactly once
- the gps_buffer evicts by age/size per §4.3 without losing ordering
- schema migration from version N to N+1 is tested
