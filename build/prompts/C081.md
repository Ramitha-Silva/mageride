## Scope
Package tracking for both parties and the trip/schedule history.
ADD: [P-07, P-09, AL-21, AL-24, AL-48, US-20.5, US-20.7, US-20.11, US-24.4].

**Fences — do not cross these:**
- The recipient screen is reached by FCM deep link (app installed) or by the SCR-WT web page (no app) — never by login.
- Completed-trip cards show the driver's REAL mobile number; it is withheld for rides cancelled before assignment (AL-48).

## Deliverables
- package track (sender) — live driver position, 4-step status bar, pickup OTP display
- package track (recipient) — live position, status, delivery OTP, driver/vehicle card, call driver
- trip & schedule history — past trips, upcoming scheduled rides, past packages; driver name + mobile + Call action opening SCR-PA-015a
- trip details with route, fare breakdown and receipt

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- the FCM deep link opens the recipient screen directly on the correct package
- a cancelled-before-assignment trip shows no driver number
- the OTPs shown match the ones the driver must enter
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
