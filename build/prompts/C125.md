## Scope
Deploy the lightweight production replica on the Contabo EU VPS exactly as specified: 11 core
containers plus the optional set, with synthetic data and a smoke suite.

**Fences — do not cross these:**
- The replica is for testing, CI and demos only — SYNTHETIC DATA ONLY. Never production data.
- This box also hosts the build. Bring builds down before bringing the replica up; the two do not fit together.
- Nominatim runs on a separate VPS (8 GB); osm-pipeline runs on schedule and exits.

## Deliverables
- infra/replica/docker-compose.light-replica.yml matching the spec's container layout and resource budgets
- HAProxy TLS termination + MQTT/TCP passthrough, MinIO object storage, monitoring stack
- synthetic data seeder — operating cities, tariffs, fee plans, drivers, vehicles, passengers, trips
- smoke suite proving the golden paths after deploy; resource-guardrail script asserting the ~18.9 GB budget
- operating runbook — bring up, bring down, back up, restore

## Definition of Done
- every container reaches healthy and total memory stays within the documented budget
- the smoke suite books a ride, runs a Mode A journey and completes a package delivery on the replica
- the guardrail script refuses to start if a heavy build is running
- a nightly pg_dump lands in object storage and restores cleanly in a test
