## Scope
The shared test infrastructure every app module and Wave 5 contract suite reuses: API fakes,
deterministic time, fixture builders, and contract checks against backend/contracts/.

**Fences — do not cross these:**
- The test kit ships in a test source set / separate artifact — it must not leak into release app binaries.

## Deliverables
- shared/kmp/src/commonTest (published test-kit artifact) — MockEngine-backed fake for every typed client
- deterministic Clock/Dispatcher harness for TTL, cadence and cycle tests
- fixture builders for every DTO and for canonical scenarios (Mode C ride, proxy ride, package delivery, Mode B subscription)
- contract tests validating fake responses against backend/contracts/ schemas

## Definition of Done
- every typed client has a fake with the same surface
- the canonical Mode C ride scenario drives the state machine from Requested to a terminal state in a test
- contract tests fail if a DTO drifts from its OpenAPI schema
