## Scope
The MageRide.Shared library every .NET service references. Cross-cutting only: HTTP conventions,
persistence infrastructure, messaging, auth, and health. ADD: [R-14, R-18, E-09, D-29, D-30,
D-31, D-32, D-38, AL-53].

**Fences — do not cross these:**
- NO EF Core / DbContext / LINQ-to-SQL / ORM change tracking anywhere (AL-53). Dapper over Npgsql only.
- No domain rules and no endpoints live here — services own their own logic.
- MassTransit is NOT a general bus; only ride-svc uses it (C032), and only where the ADD names it.

## Definition of Done
- every error response validates as application/problem+json with a stable type URI
- replaying a POST with the same Idempotency-Key returns the original status + body byte-for-byte
- outbox dispatcher wakes on LISTEN/NOTIFY in <50 ms in an integration test (E-09)
- grep -ri "EntityFrameworkCore|DbContext" backend/src returns nothing
- health endpoints report DB + Redis + Kafka reachability per D7 §5.1
