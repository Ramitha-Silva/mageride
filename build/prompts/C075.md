## Deliverables
- VoIP call screen with connecting/active/failed states and the direct-dial fallback prompt
- driver SOS — confirm, countdown, emergency-contact + admin dispatch, active-SOS state
- support — FAQ, ticket list + thread, daily-fee refund request; raise-ticket modal sheet
- notifications inbox from the local push table
- offline banner with last-known state and the app-update gate (426 handling)

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- SOS reaches the server and shows the dispatched state within the SLO
- a 426 response routes to the mandatory-update screen and blocks further use
- offline mode shows cached state rather than errors
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
