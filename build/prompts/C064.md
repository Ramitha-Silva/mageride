## Scope
The three admin directories (passenger, driver, vehicle) with multi-criteria search and tabbed
detail views over read models. ADD: [AL-40, AL-41, AL-42, D-35].

**Fences — do not cross these:**
- Read-only. Refunds and reversals stay Finance-only in C065.
- Every lookup emits a PII_READ audit event; PII fields are role-gated and masked for roles that lack the permission.
- Directories read from read models / replicas — never from a service's write path.

## Deliverables
- GET /admin/passengers (name/mobile/id/email) + /{id} with Trips / Payments / Packages / Disputes tabs
- GET /admin/drivers (name/mobile/id/nic/reg_no/level/status, verified by default) + /{id} with profile/wallet/level, linked vehicles, Trips / Wallet ledger / Daily fee / Credit transfers / Reports
- GET /admin/vehicles (reg_no/id/type/mode/owner_mobile/fleet_org/status) + /{id} with registration/insurance/revenue/tracker info, document thumbnails and Trips / Earnings / Daily fee / Reports
- PII_READ audit emission + per-role masking rules

## Definition of Done
- each directory search supports every documented criterion, singly and combined
- a Support/CSR sees masked PII where the matrix says so, and the mask is applied server-side
- one detail open produces exactly one PII_READ audit row
- a 10k-row directory search returns the first page in under 500 ms p95
