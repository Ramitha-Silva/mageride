## Scope
Mode A and Mode B tracking-session lifecycle only: Start/End Journey, the active-session mutex,
idle and geofence auto-end, the 5-minute grace restart, ratings, and tracker-ignition
auto-sessions with dashboard override. ADD: [D-03, R-15, T-04, T-11, AL-32].

**Fences — do not cross these:**
- trip-state-svc != ride-svc. Mode C rides are C032/C037 and must never appear here (R-01).
- A driver Start/End from the dashboard overrides the device state — the device is not authoritative (AL-32).

## Deliverables
- POST /v1/sessions/start, /{id}/end, /{id}/restart (5-min grace, US-5.10), /{id}/rating, /{id}/driver-rating
- active-session mutex — Redis lock:driver:{driverId} SETNX + the trips.sessions unique partial index (D-03)
- idle timer (30 min) and end-position geofence (100 m) auto-end with end_reason recorded
- ignition-driven auto-start/auto-end for tracker-equipped Mode A/B vehicles (US-3.22/3.23) with manual override
- EMQX LWT consumption (veh/{vehicleId}/status=offline) and adaptive cadence hints on veh/{vehicleId}/cmd

## Definition of Done
- a driver cannot hold two ACTIVE sessions; the DB index proves it under concurrent starts
- an idle session auto-ends at 30 min and can be restarted within the 5-minute grace window
- ignition-on auto-starts a session for a paired tracker and the dashboard still shows "journey started"
- a dashboard End Journey ends the session even while the device keeps publishing
