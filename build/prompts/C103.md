## Scope
The shared `@mageride/tailwind-preset` package and the headless component primitives every web
surface reuses. This is the single home for the D2 §A design tokens on the web. ADD: [AL-52].

**Fences — do not cross these:**
- Tailwind CSS is the SOLE styling system. MUI, Bootstrap, styled-components, Emotion and any runtime CSS-in-JS are excluded — reject them on sight (AL-52).
- CSS is compiled at build time by PostCSS inside `npm run build`. No runtime style injection.
- Headless primitives (Radix UI / Headless UI) styled with Tailwind are permitted; pre-styled component kits are not.

## Screens (baseline = wireframes)

## Deliverables
- portals/tailwind-preset — theme.extend with D2 §0.2 brand + semantic colours (light + dark), all 11 vehicle-type tokens, mode badges
- Outfit (display/headline) + Inter (body) type scale mapped to the D2 role table; 4px spacing grid; radius sm/md/lg/card; elevation
- screens config for the D2 breakpoints 375 / 768 / 1024; dark mode via the `dark:` variant
- portals/ui — shared headless-primitive components (button/CTA, field, chip, status pill, table, modal, toast, tabs, dropzone) styled with Tailwind
- shared i18n scaffolding for si / ta / en with a lint rule banning literal user-facing strings

## Definition of Done
- every colour, type, spacing and radius token in D2 §0.2 is expressed in the preset and resolvable in both light and dark
- a smoke page consuming the preset builds with zero runtime CSS-in-JS in the bundle
- a grep for mui|bootstrap|styled-components|@emotion across portals/ returns nothing
- the CTA primitive matches the D2 CTA token (height, radius, colour, label role)
