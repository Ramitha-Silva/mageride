## Scope
The durable write path off the hot path: batched COPY into the Timescale hypertable, 1-per-minute
operational sampling, and trip summaries. ADD: [T-06, T-10].

**Fences — do not cross these:**
- Raw high-frequency positions go to telemetry.positions only. Never write them to trips.position_samples.
- A slow or failed write must not affect the live map — degrade by buffering and alerting.

## Deliverables
- batched COPY writer (1k rows / 500 ms per partition) into telemetry.positions
- 1/min sampled writes into trips.position_samples + trip summary (start, end, distance, polyline)
- dead-letter handling for poison batches and backlog metrics
- idempotent writes on (vehicle_id, seq)

## Definition of Done
- sustained ingest of 3000 msg/s is written without backlog growth on the dev box profile
- a duplicate (vehicle_id, seq) batch does not create duplicate rows
- killing the writer mid-batch loses no committed offsets on restart
- the live map is unaffected while the writer is stopped for 60 s
