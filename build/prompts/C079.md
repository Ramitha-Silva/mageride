## Scope
Everything between "I have a destination" and "ride requested": multimodal results, proxy
booking, package booking, the paste-link sheet and scheduling.
ADD: [P-01, P-02, P-06, AL-18, AL-19, AL-20, AL-21, AL-36, US-8.2a-d, US-20.x, US-24.2].

**Fences — do not cross these:**
- Mode C tiers show PRICE ONLY — no minutes-away, no distance, before a driver is matched (AL-19).
- Mode A public routes come from the GTFS feed and are tagged Direct/Transit + PUBLIC (AL-18).
- Schedule Ride REQUIRES a destination; Confirm stays disabled until one is set (AL-36).
- Package pickup methods are Search / Map / Paste link (Request removed); drop-off adds Request.

## Deliverables
- ride booking — For Me / For Someone Else and Person / Package toggles, all direct GTFS routes with number + description + tag, Mode C price-only tiers, payment-method selection
- proxy rider details — name + phone, pickup via Search / Map pin / Paste link / Request location
- confirm pickup (rider side) — live GPS with adjustable pin, booker name, Confirm / Decline
- package booking — size S/M/L, description, recipient name + phone, pickup and drop-off capture, COD option
- paste-link modal sheet with Empty -> Parsing -> Resolved (pin preview + reverse-geocoded address) -> Error states
- schedule ride — mandatory destination picker, editable pickup, date/time, reminders

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- no Mode C tier displays an ETA or distance before matching
- all four Google Maps URL shapes resolve in the paste sheet, and an unparseable link offers "pick on map"
- Confirm on Schedule Ride is disabled until a destination is chosen
- a rider Decline sends no coordinates
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
