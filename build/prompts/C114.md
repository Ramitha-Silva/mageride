## Deliverables
- dashboard — active vehicles, online/stale/offline counts, today's trips, alerts feed, fleet wallet balance and next consolidated invoice
- live fleet map — MapLibre with all org vehicles (mobile- or tracker-sourced), fleet-health overlay, per-vehicle drill-in
- analytics — per-vehicle trips, distance, active hours, utilisation, idle time, date-range filters, CSV/PDF export

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- the map shows only the caller org's vehicles, verified against a second org's data
- analytics figures reconcile with the telemetry continuous aggregates
- the health overlay reflects Online / Stale / Offline transitions live
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
