## Scope
The back-office BFF foundation for all six internal roles: RBAC-scoped routing, the audit
interceptor, the dashboard with its statistics filter, moderation, platform configuration,
announcements and the GTFS manager proxy. ADD: [AL-02, AL-06, AL-37, AL-38, AL-54, D-35].

**Fences — do not cross these:**
- Deny-by-default RBAC on every endpoint. No MFA anywhere (AL-37) — D7 §4.2's `Mfa__RequiredForInternal` is stale.
- Every mutation emits an audit.events row through the interceptor. A mutation without an audit row is a bug (D-35).
- No driver-facing or passenger-facing pages are served from here.

## Deliverables
- internal sign-in (password or Google) + role-scoped menu manifest driving the portal nav
- audit interceptor on every mutating route -> audit.events (actor, action, target, before/after, ip)
- GET /admin/dashboard/stats?period=today|week|month|custom&from&to with vs-previous-period deltas + CSV export (AL-38)
- moderation — suspend/ban driver or vehicle, report review queue, delisting
- configuration — fare tariffs, daily-fee rates, voucher discount tiers, Driver-Level params, feature flags
- announcements/broadcasts; train (Mode A) registration, admin-only; Super-Admin RBAC user/role provisioning
- proxy routes for /admin/transit/gtfs/* to transit-svc (Configuration nav group)

## Definition of Done
- the RBAC test matrix covers every internal role against every admin endpoint per URD §2.3
- a mutation performed with the audit interceptor disabled fails the test suite
- the stats endpoint returns identical numbers to a direct analytics query for the same period
- no login path requests a second factor
