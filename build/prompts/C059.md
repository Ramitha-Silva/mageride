## Scope
Fleet operations: Mode A/B vehicle onboarding with named document slots, driver assignment,
tracker binding, scheduling and alarms, the live fleet map and analytics.
ADD: [AL-03, AL-10, AL-23, AL-50, AL-51, T-09, US-13.x].

**Fences — do not cross these:**
- Named document slots are: registration copy (CR) | insurance | revenue licence (all modes) + route permit (Mode A required). Approval is blocked until every required slot is verified (AL-50).
- The UI label is "Service payment" (Free/Paid); the API path `/classification` and the column `mode_b_billing` are intentionally unchanged (AL-51).
- Route-deviation and geofence alerts are Phase 3 — build the geofence CRUD, not the alerting.

## Deliverables
- POST /v1/fleets/{id}/vehicles (single) + /vehicles/bulk (CSV -> docs_pending rows + downloadable row error report)
- GET/POST /v1/fleets/{id}/vehicles/{vid}/documents — named slots reusing the ocr-svc pipeline, per-doc verified | pending | missing
- PUT /v1/fleets/{id}/vehicles/{vid}/classification (Free | Paid + default monthly fare)
- POST /v1/fleets/{id}/assignments — time-bounded driver assignment incl. temporarily-hired Mode A/B (AL-23)
- tracker binding hand-off to provisioning-svc; scheduling + schedule-not-started alarms pushed to the assigned driver app
- GET /v1/fleets/{id}/map (org-scoped live positions), /analytics, PUT /geofences
- Mode B request/subscriber/payment proxies to subscription-svc scoped by RLS (SCR-FP-011/012)

## Definition of Done
- a Mode A vehicle cannot reach APPROVED without a verified route permit
- a bulk CSV of mixed-validity rows imports the valid rows and returns a row-level error report
- an assignment expiring removes the driver's ability to select that vehicle without manual action
- the fleet map returns only the caller org's vehicles under RLS
