## Scope
The three admin directories with multi-criteria search and tabbed detail views.
ADD: [AL-40, AL-41, AL-42, D-35, US-24.9, US-24.10, US-24.11].

**Fences — do not cross these:**
- Read-only. No mutation controls beyond what the role matrix permits elsewhere.
- PII is masked per role, server-side; the client never receives unmasked data it may not show.
- Driver search defaults to verified drivers.

## Screens (baseline = wireframes)
- SCR-AP-010 · passenger_search — Find a passenger — `specs/wireframes/web_admin.html`
- SCR-AP-011 · passenger_detail — Profile + transactions — `specs/wireframes/web_admin.html`
- SCR-AP-012 · driver_search — Find a driver — `specs/wireframes/web_admin.html`
- SCR-AP-013 · driver_detail — Profile, vehicles & transactions — `specs/wireframes/web_admin.html`
- SCR-AP-014 · vehicle_search — Find a vehicle — `specs/wireframes/web_admin.html`
- SCR-AP-015 · vehicle_detail — Information & transactions — `specs/wireframes/web_admin.html`

## Deliverables
- passenger search (name / mobile / passenger ID / email) -> detail with Trips / Payments / Packages / Disputes tabs
- driver search (name / mobile / driver ID / NIC / reg no / Level / status) -> detail with profile, wallet, level, linked vehicles + Trips / Wallet ledger / Daily fee / Credit transfers / Reports
- vehicle search (reg no / vehicle ID / type / mode / owner mobile / fleet org / status) -> detail with registration/insurance/revenue/tracker info, document thumbnails opening SCR-AP-003b, and Trips / Earnings / Daily fee / Reports

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- every documented search criterion works singly and in combination
- document thumbnails on a vehicle detail open the shared viewer
- opening a detail records a PII_READ audit entry
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
