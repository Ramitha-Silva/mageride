## Scope
In-app FAQ and support tickets for both apps, plus the admin ticket queue feed.
ADD: [Epic 16, US-9.23, US-14.13].

**Fences — do not cross these:**
- FAQ content is owned by content-svc; support-svc serves and filters it, it does not author it.
- Ticket resolution UI lives in the Admin Portal (C107); this service exposes the queue API only.

## Deliverables
- GET /v1/support/faq (+ language, category filters), GET /v1/support/faq/{articleId}
- POST /v1/support/tickets (category, description, tripId?, screenshot upload), GET user tickets + detail thread
- driver daily-fee refund request category routed to Finance (US-9.23, US-14.11)
- admin queue API — list, assign, respond, resolve with audit hooks

## Definition of Done
- FAQ returns articles in the requested language with a documented fallback order
- a ticket with a screenshot stores the artifact in object storage and links it by id, not by public URL
- ticket status transitions are recorded and visible to the user in the thread
