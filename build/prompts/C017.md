## Scope
Geospatial and real-time contracts shared by both apps: H3 geocells, the adaptive publish-rate
engine, MQTT topic/payload definitions, and the SignalR hub contract.
ADD: [R-06, R-07, R-09, R-17, AL-12, AL-31].

**Fences — do not cross these:**
- Passenger view is H3 res-7 + ring(2) = 19 cells. res-8 + ring(1) is the old, wrong value (R-06).
- The H3 cell is never a final distance bound — an exact-distance post-filter is mandatory.
- Actual MQTT/SignalR socket ownership is native (C067/C076 shells); this module defines config, payloads and rules only.

## Deliverables
- shared/kmp/src/commonMain/kotlin/domain/geo — H3 res-7 + ring(2) cell set, res-5 dispatch cell, 30 s boundary hysteresis, exact-distance post-filter helpers
- AdaptiveRateEngine — phase-aware cadence table (D5 §5.2) + server cadence hints from veh/{vehicleId}/cmd, coalesce rules, 5 msg/s ceiling awareness
- MqttConfig — topic tree veh/{vehicleId}/pos/live|pos/replay|cmd|status, QoS, retain, PositionPayload codec, monotonic seq for replay (R-17)
- SignalR hub contract — group naming cell:{h3index}, ride and booker groups, reconnect/heartbeat/state-recovery rules (D6 §5.4)

## Definition of Done
- the computed cell set for a reference coordinate matches the 19-cell res-7+ring(2) expectation
- the cadence engine emits the documented interval for every phase in the D5 §5.2 table
- replay payloads carry a strictly monotonic seq and duplicates are dropped locally
- group churn is suppressed for 30 s after a boundary crossing
