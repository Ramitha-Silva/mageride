## Scope
The SignalR fan-out plane with the full visibility model: geocell groups, Mode C engagement
hiding, stale suppression, Mode B entitlement and directed revocation.
ADD: [R-06, D-22, D-23, P-13, AL-31, US-7.16, US-7.17].

**Fences — do not cross these:**
- Mode C vehicles on an active hire are excluded from public geocell groups; their position goes only to the assigned ride's group (US-7.16).
- The driver home map shows the driver's OWN active vehicle only — never other drivers (AL-31).
- A vehicle marked offline by LWT or stale beyond the freshness window is dropped from public groups.

## Deliverables
- /hubs/live — join/leave cell:{h3index}, ride:{rideId}, booker:{bookerId}:loc-req:{requestId} groups per D6 §5.1
- Mode B entitlement cache Redis share:{userId} (SET, pub/sub invalidated) checked on group join (D-23)
- share.revoked consumption -> directed RemoveFromGroupAsync to the affected passenger (D-22)
- stale-position suppression + LWT-driven removal; visibility filter for Mode A/B public vs Mode C engaged
- Redis backplane (dev/MVP) with the Redpanda backplane path documented for scale; sticky sessions
- reconnect / heartbeat / state recovery per D6 §5.4 (<5 s reconnect)

## Definition of Done
- an engaged Mode C vehicle disappears from public groups and appears only in its ride group
- revoking a Mode B share removes the passenger from the vehicle's stream immediately, without waiting for a cell crossing
- a passenger crossing a cell boundary re-subscribes with 30 s hysteresis and sees no gap
- a driver's home map subscription receives only their own vehicle
