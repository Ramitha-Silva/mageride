## Scope
The passenger home map and destination search. ADD: [R-06, AL-17, AL-23, AL-26, D-14,
US-7.1-7.17, US-15.x].

**Fences — do not cross these:**
- Destination search is GEO-ONLY — no route-number typing, no route rows in predictions (AL-17).
- A Mode B marker opens the access-request screen (SCR-PA-024), NOT the Mode A popup (AL-23).
- Engaged Mode C vehicles and stale vehicles must not be rendered (US-7.16/7.17).

## Deliverables
- live map with geocell-driven markers, per-type colour tokens, clustering, heading, recenter, current location
- mode/type filter overlay with vehicle icons tinted by their AL-09 colour (not plain dots)
- Mode A vehicle popup — route, distance, ETA, driver info; Mode B markers route to SCR-PA-024
- location search — Nominatim predictions + saved/recent, no route rows
- offline state with last-known positions and a reconnect indicator

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- typing a route number returns places only, never a route row
- tapping a Mode B marker navigates to the access-request screen with the vehicle ID pre-filled
- an engaged Mode C vehicle disappears from the map during its hire
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
