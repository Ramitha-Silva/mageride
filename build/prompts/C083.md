**Fences — do not cross these:**
- The language selector is NOT on Edit Profile — it lives in onboarding and Settings only (AL-26).

## Deliverables
- saved addresses — Home / Work / custom labels, add via map pin, edit, delete
- add-address ModalBottomSheet — Address Line 1/2/3 + Label, Save
- profile & settings — user ID, language, notification preferences, Home & Work map pins, default payment method, Help & Support
- edit profile — name, photo, notification preferences, SOS contacts, no language selector
- nav drawer — Private transport, My subscriptions, Saved addresses, Profile & settings, Help, Log out

## Definition of Done
- every screen matches its wireframe layout, controls, states and navigation
- no language control exists on Edit Profile
- a saved address round-trips all three lines plus the label
- changing the default payment method is reflected on the next booking
- every screen listed under `## Screens` is implemented to match the layout, controls,
  states and navigation shown in its wireframe — the wireframes are the team-approved
  baseline; any deviation requires a micro-change-set first. D2' still governs design
  tokens, styling rules and trilingual (Si/Ta/En) string resources.
