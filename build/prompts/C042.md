## Scope
Read APIs over the live and historical planes: nearby vehicles with type filters, trip history
and detail, driver earnings, and location search backed by self-hosted Nominatim.
ADD: [R-06, D-14, MAP-01..MAP-10, AL-17].

**Fences — do not cross these:**
- The same visibility rules as fanout apply here — engaged Mode C and stale vehicles are excluded.
- Destination search returns geocoded places and saved/recent only. No route-number rows (AL-17).
- No Google Maps, no public OSM tile servers.

## Deliverables
- GET /v1/nearby (lat/lng/radius/types incl. trains) reading Redis GEO with an exact post-filter
- GET /v1/trips/{userId}, /{tripId} (+ polyline), GET /v1/earnings/{driverId} and /sessions
- place search + reverse geocode proxy to Nominatim with caching
- internal gRPC surface for other services; read-replica routing with read-after-write only where required

## Definition of Done
- nearby excludes engaged Mode C vehicles and anything stale beyond the freshness window
- a type filter returns exactly the requested vehicle types including trains
- trip detail returns the stored polyline, not a re-derivation from raw positions
- search never returns a route row for a typed route number
