## Scope
In-app voice ("Free call") via LiveKit + coturn, with trip-scoped signalling tokens.
ADD: [D-24, AL-11, AL-48, P-05].

**Fences — do not cross these:**
- Number masking is WITHDRAWN (AL-48). `callType` is `free_voip` only; "Normal call" is a client-side tel: dial with no server round-trip.
- The masked-PSTN bridge, proxy-DID lease and D-25 masked-SMS relay must NOT be built.
- For proxy rides the call always binds the driver to the RIDER, never the booker (P-05).

## Deliverables
- POST /v1/voip/token — trip-scoped LiveKit token expiring at trip end
- POST /v1/calls/start — callType free_voip only, logging comms.call_log (best-effort, call_type ∈ free_voip | direct_dial)
- LiveKit SFU + coturn deployment config (host UDP, not via HAProxy)
- VoIP-failure signal so the client can offer the direct-dial prompt; recordings off by default

## Definition of Done
- a signalling token is rejected after trip end
- a proxy ride's driver token resolves to the rider identity, never the booker
- no code path provisions a masked DID or sends a masked SMS relay
- call_log rows distinguish free_voip from client-reported direct_dial
