## Scope
Prove the documented degradation and recovery behaviour by breaking things on purpose.
ADD: [R-04, R-09, R-15, R-16, E-09, D-08, D-33].

**Fences — do not cross these:**
- Drills run on the replica. Each drill has a defined blast radius and a rollback.
- A drill that cannot be recovered from within RTO is a finding, not a footnote.

## Deliverables
- infrastructure drills — Redis loss, Postgres failover, Redpanda broker loss, EMQX node loss, outbox dispatcher stall
- client-side drills — reconnect storm, replay flood, mass driver offline (LWT), network partition
- degradation verification against ADD §14.1 for each drill (what still works, what is refused)
- DR drill — restore from backup, measure against RPO 5 min / RTO 30 min
- findings + runbook updates

## Definition of Done
- every drill matches the documented degraded behaviour, or the deviation is filed as a finding
- a Redis flush loses no offer expiry thanks to the Quartz backstop
- the DR restore meets RPO and RTO with measured numbers
- each drill has a runbook entry with detection signal and first action
