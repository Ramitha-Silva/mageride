## Scope
The CI entry point and the container build templates: a GitHub Actions matrix over
backend / android / ios / portal, the three Dockerfile shapes, and the Testcontainers harness.
Full CD (ArgoCD, promotion, rollback) is C124.

**Fences — do not cross these:**
- The ios matrix leg pins runs-on macos-14; it must never be scheduled on the Linux build host.
- Migrations are validated by applying versioned .sql twice — never by `dotnet ef`.

## Deliverables
- .github/workflows/ci.yml — matrix [backend, android, ios, portal] + spectral contract lint + migration idempotency job
- infra/docker/Dockerfile.service (aspnet:10.0-alpine), Dockerfile.worker (runtime:10.0-alpine, tcp-adapter), Dockerfile.portal (node24-alpine)
- backend/src/MageRide.TestKit — Testcontainers fixtures for Postgres(timescaledb-ha) / Redis / Redpanda
- .github/workflows/README.md — how a component's verify_cmd maps onto a CI job

## Definition of Done
- ci.yml parses and every job has an explicit runs-on
- Dockerfile.service builds MageRide.Shared to a runnable non-root image with the D7 healthcheck
- a Testcontainers-backed test in MageRide.Shared.Tests starts Postgres and applies migrations
- the migration job fails the build if a second apply is not a no-op
